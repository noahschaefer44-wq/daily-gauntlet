# Daily Gauntlet

All your daily puzzles in one place: Wordle, Connections, Krillion, Magnitudle and 70+ more.

- Every puzzle gets a cover and a link to the original game.
- Mark a puzzle as solved. When you come back from a game tab, the page asks if you solved it.
- Progress resets at midnight. Streaks, favorites and filters are saved in your browser (localStorage).

Plain HTML, CSS and JavaScript. No build step. Add a game by adding an entry to `games.js`.

All games belong to their creators. This site only links to them.
